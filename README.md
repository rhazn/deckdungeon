# Deck Dungeon

Deck Dungeon is a cooperative roguelike collectible card game. Players explore dungeons with a party of characters, collect resources, open loot boxes to earn cards, and build out a persistent base — all without pay-to-win mechanics. The core fantasy is building a perfect party through drops and crafting, inspired by games like Pokémon and Diablo.
