# Deckdungeon

Deckdungeon is a cooperative roguelike collectible card game set in a high fantasy world with steampunk elements. Players explore dungeons, collect resources, build a persistent base, and customize a party of characters. The game is currently in active development with working prototypes for combat and dungeon exploration.

## Features

- **Dungeon Exploration**: Explore dungeon decks with scenario cards and boss fights.
- **Base Building**: Upgrade your mobile base using resources gathered from dungeons.
- **Character Customization**: Collect characters from loot boxes and enhance their skills.
- **Market Trading**: Trade cards and lootboxes with other players.
- **Cooperative Gameplay**: Play with a party of characters in strategic card-based combat.

## Development Status

The project is in early alpha stages. Functional prototypes exist for:
- CLI-based combat
- Web-based combat
- Dungeon combat (multiple scenario cards + boss)
- Dungeon exploration (shuffled deck, boss in last 30%)

Future milestones include Alpha 1 (preconfigured dungeon runs), Alpha 2 (user accounts and stats), and Alpha 3 (drops and character customization).

## Setup and Usage

Detailed setup instructions for the CLI and Web prototypes are not yet documented. The project is under active development, and installation guides will be provided as the prototypes mature.
