# Deck Dungeon

Deck Dungeon is a cooperative roguelike collectible card game. Players explore dungeons with a party of characters, collect resources, build a persistent base, and earn loot boxes to customize their roster — inspired by games like Pokémon and Diablo.

## Status

The project is in active design and prototyping. Completed milestones include CLI and web combat prototypes and a dungeon prototype. Upcoming milestones include a full Alpha release with preconfigured dungeon runs, user accounts, and character customization from drops.
